---

## 본론
웬만한 설정은 기본값 혹은 비용이 제일 저렴한 것으로 선택합니다. 결과적으로 문제가 발생하면 설정을 수정해서 해결했습니다.

### 클러스터에 노드 그룹이 생성 안 되는 문제
AWS추천하는 role의 정책 목록은 아래와 같습니다.
1. `AmazonEC2ContainerRegistryPullOnly`
2. `AmazonEKSWorkerNodeMinimalPolicy`
3. `AmazonElasticContainerRegistryPublicReadOnly`

이대로 진행하면 클러스터에 노드 그룹이 생성되지 않는 문제가 발생합니다. `AmazonEKS_CNI_Policy`을 추가하면 정상적으로 생성됩니다.

### kubectl에 EKS 클러스터를 추가했는데 kubectl get nodes 시 에러 발생
`kubectl`에 EKS 클러스터를 추가하고 `kubectl get nodes` 시 `couldn't get current server API group list: the server has asked for the client to provide credentials`라는 에러 메시지가 출력됩니다.

클러스터의 Access에 IAM 사용자를 추가하고 `AmazonEKSClusterAdminPolicy`를 추가하면 `kubectl get nodes` 사용 가능합니다.

### 배포했는데 서버가 504만 반환하는 문제
`kubectl get pods`로 확인해본 결과 pods가 뜨지 못하고 있었습니다. 비용 문제로 노드 그룹 생성할 때 t3.small 2개로 설정했더니 자원이 부족했던 것으로 판단, t3.medium 2개로 교체했습니다. 결과적으로 서버가 정상 작동했습니다.
